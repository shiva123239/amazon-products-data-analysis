# 📦 Amazon Products Data Analysis

## 📌 Overview
This project analyzes a large-scale Amazon products dataset (1.4M+ records) to uncover pricing trends, rating patterns, and category-level insights using Python.

## 🎯 Objectives
- Clean and preprocess large e-commerce datasets
- Analyze product pricing and customer ratings
- Identify top-performing product categories
- Generate actionable business insights

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Key Insights
- Most products fall within a competitive low-price range
- Product ratings vary significantly by category
- Pricing alone does not guarantee higher customer ratings

This project demonstrates the ability to analyze large-scale e-commerce data and extract insights relevant to real-world business problems.
